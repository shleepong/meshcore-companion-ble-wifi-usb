Chrome ou Edge requis, sur Windows ou Android. Safari (iOS/Mac) ne supporte ni le Bluetooth ni le port série depuis un navigateur : aucun outil web ne peut le faire, ce n'est pas spécifique à cette page.
!
Firmware communautaire, pas officiel. Cette page parle aux builds DUAL_BLE_WIFI (BLE + USB + WiFi simultanés) et EXCLUSIVE_BLE_WIFI (BLE ou WiFi, un seul actif à la fois, bascule par redémarrage) décrits dans le dépôt associé. Elle n'a aucun effet sur un firmware MeshCore standard. Solution de dépannage en attendant qu'un firmware companion multi-transport soit proposé officiellement en amont.
